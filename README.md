## 🎮 Флагманский проект: «Психиатр»

**Платформы:** VK Play, itch.io (WebGL)  
**Исходный код:** https://github.com/eva-craft/Psychiatrist  
**Технологии:** JavaScript (ES6+), HTML5 Canvas, CSS3  
**Роль:** Sole Developer — геймдизайн, программирование, UI/UX, публикация

### О проекте

«Психиатр» — симулятор управления психиатрической клиникой с элементами стратегии и менеджмента. Игрок выбирает врача-психиатра (12 персонажей с уникальными способностями), открывает клинические отделения (13 уровней с возрастающей сложностью) и лечит пациентов, подбирая препараты под диагнозы из справочника МКБ-10.

### Ключевые механики

- **Система болезней и препаратов** — 80+ расстройств МКБ-10, каждое лечится определённым набором из 10 препаратов. Эффективность зависит от тяжести болезни (1–5), изученных технологий и бонусов врача.
- **Дерево исследований** — 30+ технологий с зависимостями (психофармакология, нейробиология, судебная психиатрия и др.), влияющих на лечение, побочные эффекты и поведение пациентов.
- **Управление персоналом** — найм санитаров, медсестёр, ординаторов и прибора ЭСТ. Каждый сотрудник даёт уникальный бонус (замедление ухудшения здоровья, усиление препаратов, дополнительные очки исследований).
- **Динамическая симуляция** — пациенты перемещаются по палате, дерутся, спят ночью, выздоравливают во сне. Система коллизий и расталкивания предотвращает наложение спрайтов.
- **Цикл дня и ночи** — утро/день/вечер/ночь влияют на поведение пациентов и скорость ухудшения здоровья.
- **Система сохранений** — полное сохранение состояния в файл .psy (JSON) с восстановлением всех параметров уровня.

### Технические решения

- **Масштабирование под любые экраны** — игровое поле фиксированного размера (1400×820) масштабируется через CSS transform: scale() с сохранением пропорций; отдельная адаптация под мобильные устройства (горизонтальная прокрутка панели препаратов, увеличенные кнопки).
- **Кастомная система диалогов** — замена браузерных alert()/confirm() на собственные модальные окна с Promise-based API для управления потоком выполнения.
- **Защита от зума и мультитача** — блокировка pinch-zoom, двойного тапа, Ctrl+wheel и жестов Safari для стабильного игрового опыта на мобильных.
- **Взвешенный выбор болезней** — каждая болезнь имеет вес (частоту появления) и категорию; уровни настраивают приоритеты через categoryWeights, что позволяет создавать тематические отделения.
- **Индивидуальные таймеры пополнения препаратов** — каждый препарат пополняется по своему интервалу, зависящему от редкости и уровня, что создаёт экономическое давление без микроменеджмента.
- **Система бонусов врачей** — 12 психиатров с уникальными модификаторами, интегрированными в общую логику через единую функцию applyDoctorBonus().

### Работа с ИИ в проекте

Использован DeepSeek для генерации первичных черновиков кода (UI-компоненты, шаблонные функции) и документации. Ключевые архитектурные решения, интеграция систем, отладка и оптимизация выполнены самостоятельно.

## Другие проекты

### «Wizardrunner» — голосовой раннер

**Платформы:** itch.io (WebGL), Android (APK), GitHub  
**Ссылки:** https://evacraft.itch.io/wizardrunner • https://github.com/eva-craft/Wizardrunner  
**Технологии:** JavaScript (ES6+), HTML5 Canvas, Web Speech API, Capacitor, Android Studio  
**Роль:** Sole Developer — геймдизайн, программирование, UI/UX, сборка под Android, публикация

#### О проекте

Бесконечный раннер с магом, управляемым голосом. Игрок произносит заклинания, чтобы активировать способности: бесплотность, уничтожение препятствий, магнетизм, откат во времени, ураган и левитацию. 7 уровней с уникальными фонами (ночной лес, пустыня, академия магии, вулкан, храм некромантов, чародейский лес, мир магии) и собственной стилистикой препятствий.

**Ключевые механики:**

- **Голосовое управление** — распознавание русской речи через Web Speech API с немедленной реакцией на interim-результаты (срабатывание почти мгновенно, без ожидания финального распознавания).
- **Семь заклинаний** — «Фокус Покус» (бесплотность), «Абракадабра» (уничтожение препятствия), «Магнифико» (магнетизм), «Темпус» (откат на 7 секунд), «Торнадо» (ураган), «Левитация», «Сангуис» (самоисцеление).
- **Система здоровья и конфуза** — при столкновении игрок теряет сердце и на 2 секунды теряет контроль (визуальный хаос, вибрация, вспышка).
- **Плавная прогрессия** — 7 уровней с ростом скорости, плотности препятствий и шанса двойного спавна.
- **Адаптивный интерфейс** — HUD, прогресс уровня, health bar, индикаторы активных заклинаний.

**Технические решения:**

- **Сборка под Android** — игра скомпилирована в нативное Android-приложение с помощью Capacitor и Android Studio: WebView-обёртка с доступом к микрофону, вибрации и системным жестам, сборка APK и подготовка к публикации.
- **Архитектура состояний** — единый объект G со всеми параметрами игры, что упрощает сохранение/восстановление (система «Темпус»).
- **История для отката времени** — кольцевой буфер кадров (12 секунд) с полным снапшотом состояния: позиции, препятствия, монеты, таймеры, здоровье.
- **Кастомная система частиц** — гравитация, затухание, цветовые вспышки под каждое заклинание.
- **Адаптация под мобильные** — блокировка зума, поддержка тапов и двойного тапа, вибрация.
- **Процедурная генерация фонов** — уникальные бэкдропы для каждого уровня (пирамиды, замок, вулкан, храм, лес, космос) с параллаксом.

### «Оперный Певец» — музыкальный платформер

**Платформы:** itch.io (WebGL), GitHub  
**Ссылки:** https://evacraft.itch.io/opera-singer • https://github.com/eva-craft/Opera-Singer  
**Технологии:** JavaScript (ES6+), HTML5 Canvas, Web Audio API  
**Роль:** Sole Developer — геймдизайн, программирование, UI/UX, публикация

#### О проекте

Музыкальный платформер, где игрок управляет оперным певцом и атакует врагов нотами. 21 опера — от «Руслана и Людмилы» до «Валькирии» — каждая с тремя этапами (сбор нот, уничтожение врагов, босс) и уникальным визуальным стилем. Три типа голоса (тенор, баритон, бас) с разными диапазонами, силой и звучанием.

**Ключевые механики:**

- **Система голосов** — три типа с уникальными диапазонами MIDI, кривыми урона и цветовыми палитрами. Зарядка ноты (мощность выстрела) зависит от длительности удержания.
- **Арии** — по 5–10 способностей на каждый голос: заморозка, лечение, залп нот, замедление, неуязвимость, щит, двойной прыжок, магнит, ярость, телепорт, цепная молния, чёрная дыра, зеркальный клон, откат времени, низкая гравитация.
- **21 опера с уникальными врагами** — у каждой оперы свой тип врага (богатырь, морское чудище, самозванец, гомункул, крылатый гусар, денди, карточный дух, половецкий всадник, жрец, куртизанка, шут, инквизитор, тореадор, слуга Царицы Ночи, слуга с подносом, каменный гость, монах, рыцарь, нимфа, призрачный матрос, валькирия) и свой босс.
- **Система опыта и характеристик** — 10 уровней, очки вкладываются в мощь голоса, дальность, фразировку, артистизм и исполнительность.
- **Внутриигровые диалоги** — сюжетные реплики перед каждым этапом с портретами персонажей, нарисованными процедурно на canvas.
- **Сохранение/загрузка** — полное состояние уровня в файл .song (JSON).
- **Опера-специфичная стилизация** — 21 уникальная тема (цвета платформ, фоны, декорации: купола, пузыри, кресты, колбы, снежинки, люстры, карты, костры, пирамиды, розы, маски, башни, солнце, звёзды, лозы, луна, лютни, лебедь, сердца, волны, руны).

**Технические решения:**

- **Web Audio API** — синтез вокала через формантный синтез (4 форманта на голос), вибрато, джиттер, шиммер, дыхание; свёрточный реверб с процедурным импульсом для «оперного зала». Дополнительно — загруженные сэмплы голосов (тенор, баритон, бас) с питч-шифтингом.
- **Кастомная физика платформ** — статические, движущиеся по X/Y и исчезающие платформы с проверкой достижимости прыжка и строгой проверкой пересечений с учётом движения.
- **Земля с ямами** — процедурная генерация суши с безопасными зонами на старте и перед боссом.
- **Система эффектов** — 15+ активных эффектов с визуальными индикаторами, таймерами и стекированием.
- **Универсальное диалоговое окно** — Promise-based API для confirm/alert/choice с SVG-иконками.
- **Занавес и меню паузы** — анимированные оперные занавесы на CSS.
- **Адаптация под мобильные** — блокировка зума, тач-управление, адаптивные размеры.
